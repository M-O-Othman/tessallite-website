What Tessallite is

The place your numbers get their meaning.

Tessallite is a semantic layer and query acceleration platform. To your tools it looks like a database. To your business it is where every important number has one approved definition, one access policy, and one fast path — modelled once, inherited by every dashboard, workbook, and AI agent.

1

Model

Define dimensions, measures, joins, calendars, hierarchies, and glossary terms once — versioned and deployed like software, so what is served is always what was approved.

2

Govern

Roles, personas, row security, and column controls are written once and enforced everywhere automatically — never re-implemented per tool.

3

Route

Every query takes the fastest path that is provably exact — aggregate, pocket table, or source. Speed never changes the answer.

4

Explain

Owners, freshness, lineage, and route detail travel with every result — so when someone asks where a number came from, there is an answer.

Enterprise control

Security rules travel with every answer.

One set of access rules, enforced at one chokepoint. Whether the question arrives from Excel, a BI tool, SQL, an API, or the AI agent, the same row, column, and persona policies decide what comes back.

Audience-aware models

Personas shape exactly which measures, dimensions, hierarchies, and filters each audience sees — and administrators can preview any audience’s view before it ships.

Row and column controls

Row security, data tags, and column restrictions hold across every protocol. A field hidden in the dashboard is hidden in Excel, SQL, and chat too.

Audit and trace

Every answer carries its evidence — query log, route, owner, freshness, and lineage — ready for any reviewer who asks.

Performance, measured

A terabyte benchmark. Answers for pennies on the simple question.

Tessallite watches your query patterns, builds the right summary tables automatically, and keeps them fresh. On the published TPC-DS SF1000 run (BigQuery), the simple everyday question that cost $330 per 1,000 unaccelerated runs came back for 5 cents when accelerated — identical to the unaccelerated Tessallite route, not an independent BigQuery baseline. Medium and heavy questions in the same mix cost more; do not annualise the simple bar across every dashboard. The hosted trial at cloud.tessallite.io is the SF1 demo, not the terabyte dataset.

Aggregates

Rollups for the questions your teams actually ask — created, refreshed, and retired automatically. Nobody hand-maintains a summary table, ever.

Pocket tables

Hot slices of big fact tables, cached close to the query, so repeated filtered analysis stops re-scanning the source.

Exactness, guaranteed

If a prepared answer cannot be exact for a query, Tessallite goes to the source and gets the right one — then learns from the miss. Fast never means wrong.

Connected tools

Your tools already speak its language.

Each deployed model is simultaneously an OLAP cube for Excel and Power BI, a PostgreSQL database for any SQL client, a REST API for your applications, and grounded context for AI — defined once, identical everywhere, nothing to install on the client.

Excel and Power BI

Connect natively over XMLA: browsable cubes, friendly field names, drillable hierarchies, and refreshable workbooks — no add-ins required.

SQL and BI tools

Any PostgreSQL-compatible client just works — DBeaver, Tableau, pgAdmin, psycopg2, or your own drivers — and sees only the governed model.

Apps and agents

Headless APIs, embeddable chat, and AI-assistant integration put governed answers inside your own products and workflows.
