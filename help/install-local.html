Local installation

Install Tessallite Community Edition on your own machine.

Use this guide after you have a Community licence and the signed download bundle. It explains the local Docker Compose path in the language an evaluator or platform owner needs before first launch.

Before you start

  • A Tessallite Community licence file.
  • The signed Community release bundle.
  • Docker and Docker Compose v2 installed.
  • At least 8 GB RAM available for a smooth evaluation.
  • Ports 3000, 5433, and 8080 free on the host.

Need the files?

Start with the licence and download pages, then return here.

Get a licence · Download bundle

1. Verify the release

Check the release before unpacking or running it.

sha256sum -c SHA256SUMS

The Download page includes the full signature verification command and evidence-pack notes.

2. Unpack the bundle

tar -xzf tessallite-community-X.Y.Z.tar.gz
cd tessallite-community-X.Y.Z

Replace X.Y.Z with the release version shown on the Download page.

3. Add the licence

cp /path/to/tessallite-license.json ./license.json

Keep the licence file private. It is used locally by the stack during startup.

4. Start Tessallite

./install.sh

The installer prepares configuration, starts the containers, and runs the platform checks.

5. Open the product

When the installer reports success, open:

http://localhost:3000

Use the system-admin credentials created during setup. If the page is not ready immediately, wait a minute and refresh.

What runs locally

A complete evaluation stack.

The local bundle starts the web UI, model service, query router, optimizer, scheduler, gateway, and PostgreSQL metadata store. BI clients connect through the gateway; user queries still follow the governed Tessallite path.

Common first checks

  • If Docker is not running, start Docker and rerun the installer.
  • If a port is already in use, stop the conflicting process before starting Tessallite.
  • If the UI is not ready, wait for services to finish starting and refresh the browser.
  • If the licence is rejected, confirm that the file was copied as license.json.
